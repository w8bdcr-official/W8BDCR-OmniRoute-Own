# Contributing — W8BDCR OmniRoute

Contributions are welcome, in this order:

1. Open an issue first for a new feature or a behaviour change, so
   the change can be agreed before code is written.
2. Keep changes small and in W8BDCR's own wording and branding.
3. Test the installer path you touched (`bash -n` at minimum, and a
   real Termux run when you can).
4. Never include a real API key, token, or account credential in any
   file, example, or screenshot.

By contributing, you agree your work may be released under this
repo's MIT license.

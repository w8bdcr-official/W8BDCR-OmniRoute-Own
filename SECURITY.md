# Security — W8BDCR OmniRoute

This installer runs on your own phone, and your provider keys stay on
your own phone. Do not open an issue, a pull request, or a message
that contains a real API key — rotate that key with its provider
first, then report the problem without the key.

If you find a security problem in this repo's own scripts (not in the
upstream gateway itself), tell W8BDCR through @BDCRTEAM and describe
only what is needed to reproduce it. Do not publish a working exploit
before a fix is available.
